# AutoMecaTech Frontend

## Requisitos Previos
- Node.js 18 o superior
- npm 9 o superior (incluido con Node.js)

## Instalación
1. Clonar o descargar el repositorio del frontend:
   ```bash
   git clone <url-del-repo-frontend>
   cd frontend
   ```
2. Instalar dependencias (cuando se definan):
   ```bash
   npm install
   ```

## Ejecución en Desarrollo
1. Ejecutar el servidor de desarrollo (cuando se configure el proyecto):
   ```bash
   npm run dev
   ```
2. Acceder en el navegador a la URL que indique la terminal (por defecto http://localhost:5173).
