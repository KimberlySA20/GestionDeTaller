# AutoMecaTech Backend

## Requisitos Previos
- Node.js 18 o superior
- npm 9 o superior (incluido con Node.js)

## Instalación
1. Clonar o descargar el repositorio del backend:
   ```bash
   git clone <url-del-repo-backend>
   cd backend
   ```
2. Instalar dependencias (cuando se definan):
   ```bash
   npm install
   ```

## Ejecución en Desarrollo
1. Ejecutar el servidor de desarrollo (cuando se configure el proyecto):
   ```bash
   npm run dev
   ```
2. El backend escuchará en el puerto configurado (por defecto http://localhost:3000).
